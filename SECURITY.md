# Security policy

Report suspected vulnerabilities privately through this repository's **Security** tab → **Report a vulnerability** (GitHub private vulnerability reporting). Include affected versions or commit, reproduction steps, impact, and a suggested fix if available. Avoid public issues or pull requests containing exploit details or credentials. If private reporting is unavailable, ask the maintainers to enable it through a public issue without disclosing vulnerability details.

Scope includes authentication and session handling, authorization, data access, Notion imports, database operations, and deployment or CI configuration in this repository. Third-party platform vulnerabilities should be reported to the relevant provider. Do not access other people's data or run destructive tests against hosted deployments.
