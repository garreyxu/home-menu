## 2. 板子结构
- 顶部一行：上一周 / 本周 / 下一周（不变），右侧小字「11月8日–11月14日 · 已点 N 道」（Noto 13px，muted）。下面一道 sumi 3px 粗线。
- 粗线下一行：「＋ 自定义（外卖、聚餐…）」按钮：shu 1.5px **虚线**圆角胶囊、shu 字 13px 700、透明底，高 32（触屏热区 44）。
- 表格：星期列 44px（毛笔 18px，今天 shu 色 + 左侧 4px shu 竖条），早 / 中 / 晚 三列表头毛笔 20px。
- 格子：1px dashed `rule`，圆角 3，内边距 4，条目竖排 gap 4；空格居中一个淡色「＋」（点了 = 打开该格的添加，见 §4）。

## 3. 条目小牌（chip）—— 解决「字太大、× 抢戏」
- 高 28，胶囊圆角 14，底 `#FFF8EC`，1px `#CDBB9C` 边；左 24px 圆形缩略图（thumb.webp），菜名 **Noto Sans SC 13px / 500**（不用毛笔），单行省略号；`title` 属性放全名。
- **×**：13px，muted 色，**默认透明**；chip `:hover` / `:focus-within` 时显示；点击热区 24×24（桌面）。触屏不显示 ×，删除走长按菜单（§6）。
- 格子放不下：最多显示 3 条，再多显示「+N」小牌（沿用 v1）。
- **自定义条目**：同尺寸，**shu 1px 虚线框、透明底**，左边用 24px 方形朱印「外」（shu 底、paper 字、毛笔 15px、`rotate(-6deg)`）代替缩略图。点它可改名（见 §5）。

## 4. 「＋添加」（F2 + I1）
- 文案全站统一「＋添加」；已加过显示「已加 N 次」（不变）。
- **桌面 ≥1440（板子常驻）**：点卡片「＋添加」→ 板子进入「选格」模式：
  - 板顶出现一条 shu 底提示条：「把『番茄炒蛋』放到哪一顿？」+ 右侧「取消」。
  - 所有格子 hover 时 shu 虚线框 + `paper-shade` 底；已含这道菜的格子灰掉并在 hover 时提示「这顿已经有了」。
  - 点格 → 加入，提示条消失，新 chip 闪一下 shu 外发光 600ms。Esc / 取消 / 点板外退出。
  - 格里已有的菜照常显示，所以「已有菜看得见」天然满足。
- **<1440（抽屉 / 手机）**：打开底部 Sheet「『番茄炒蛋』加到哪一顿？」，7×3 表，每格写已有菜名（Noto 11px，顿号分隔，最多两行省略），空格写「空」；选中格 shu 2px 实线框 +「✓ 加这顿」；底部大按钮「添加」（shu 胶囊，高 48）。格子 ≥44px 高。效果图见 `phone.png` ③。
- 两步内完成：点「＋添加」→ 点格（桌面）/ 点格 + 添加（手机）。

## 5. 自定义条目（J1）
- 点「＋ 自定义」→ 小弹层（桌面 Popover 锚在按钮下，手机 Sheet）：
  - 输入框「写点什么，比如：寿司外卖」，40 字上限，计数 `12/40`；
  - 下面同一张 7×3 选格表（同 §4 手机版），必须选一格；按钮「放进去」。
  - 同格同名提示「这顿已经有了」。
- 点已有自定义 chip（桌面）/ 长按菜单「改名」（手机）→ 同一弹层，预填名字和格子。

## 6. 拖拽与「移到…」（K2）
- 库：dnd-kit（v1 已定）。PointerSensor 桌面 `distance: 6px` 激活；TouchSensor `delay: 350ms, tolerance: 8px`（长按）。
- **拖起**：原位置留半透明（opacity .3、虚线边）占位；跟手的是 chip 放大版（宽 170、paper 底、shu 1px 边、`box-shadow: 0 10px 22px rgba(0,0,0,.25)`、`rotate(-3deg)`）；光标 `grabbing`。
- **悬停目标格**：shu 2px 虚线框 + `rgba(200,48,40,.06)` 底 + 居中小字「放这里」（shu 12px）。目标格已有同一道菜：框变 muted 色，小字「这顿已经有了」，松手回弹到原格，toast 同文案。
- **松手**：乐观更新，调 move API；失败回滚 + toast「没挪成，再试一次」。
- 自定义条目同样可拖。
- 键盘：chip 聚焦后 Space 拿起，方向键换格，Space 放下，Esc 取消（dnd-kit KeyboardSensor），aria-live 播报「已移到周三晚饭」。
- **手机兜底**：长按 chip（未拖动就松手）→ 底部菜单：标题行（缩略图 + 「咖喱牛肉 · 周一午」）、「移到…」、「改名」（仅自定义）、「从这顿删掉」（shu 色）、「取消」；每项高 ≥48。
  - 「移到…」→ Sheet「把『咖喱牛肉』移到哪一顿？」，7×3 表同 §4，当前格 `paper-shade` 底 +「现在在这」不可点；选中格「✓ 移到这」；按钮「移过去」。效果图 `phone.png` ①②。
