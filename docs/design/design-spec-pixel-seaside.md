# 我家海上食堂：设计说明 v1（像素风）

状态：登录、菜品墙和一周菜单已按本文实现。照片详情、拖拽排菜、购物清单还没有。参考效果图见文末。
已定：全家共用一个账号、网站完全私密；一周从周日开始，早中晚三餐都排；Next.js + shadcn/ui + Tailwind。
版权：全部素材自己画或自己生成，不用开罗游戏的任何图、角色和字体。

## 1. 设计原则
- 外层（背景、边框、按钮、图标、标题）用像素风，菜品照片保留真实照片。
- 菜名和正文用正常字体，像素字只用在标题、按钮和数字角标上。
- 像素素材一律按整数倍缩放（1x/2x/3x/4x），加 `image-rendering: pixelated`，不能用小数倍。
- 不做金币、人气、购物车这类游戏数值，效果图里的这些只是装饰。

## 2. 配色（Tailwind theme tokens）
| token | hex | 用途 |
|---|---|---|
| `sea` | #1F8A8A | 主色：选中的分类、链接、焦点环 |
| `sea-deep` | #0E4F5C | 顶栏、底栏、一周菜单表头 |
| `sand` | #F3E3C3 | 页面底色（上面平铺像素沙纹） |
| `cream` | #FFF6E3 | 卡片和面板的底色（不透明） |
| `coral` | #E2533B | 主按钮“+加入”、当前日期标记 |
| `sun` | #F6C445 | 强调：角标、已加入状态 |
| `ink` | #2B1E16 | 像素描边、正文文字 |
| `muted` | #7A6650 | 次要文字、空格子提示 |
| `kelp` | #4E9F3D | 成功提示 |
对比度要求：正文和菜名在 `cream` 上至少 7:1（ink on cream 满足），按钮文字在 coral 上用白色，至少 4.5:1。文字绝不直接放在像素背景上。

## 3. 字体
- 标题、按钮、分类、星期表头：Fusion Pixel 12px（缝合像素体，开源协议待技术负责人确认），只用 12/24/36px 这三档整数倍字号。
- 菜名：Noto Sans SC 600，手机 16px，桌面 18px，带鱼屏 20px。
- 正文和说明：Noto Sans SC 400，14 到 16px。
- 数字（几道菜）：Fusion Pixel。
- 字体走 Google Fonts 按需切片加载，像素字体自托管，用 WOFF2 格式。

## 4. 像素描边和阴影（全站统一）
- 描边：2px 的 `ink` 实线，四个角各切掉 2px，做出像素圆角（用 `clip-path`，或者 9-slice 边框图）。
- 阴影：不用模糊阴影，统一向右下偏 4px 的 `ink` 实色块，透明度 25%。
- 按下状态：阴影变成 0，元素向右下移 2px。
- 键盘焦点全站统一：2px 的 `ink` 描边，外面再加一圈 `sun`。分类、按钮、格子、链接和输入框都用这一套。
- 间距基准是 4px（Tailwind 默认），组件内边距 12 或 16，卡片间距 16，带鱼屏上 20。

## 5. 组件
### 5.1 顶部横幅 SceneHeader
- 像素场景：码头小木屋、条纹遮阳棚、海、海鸥，居中显示像素字标题「我家海上食堂」。
- 高度：手机 160px，桌面 200px，带鱼屏 220px。场景图左右分成两段素材，中间用海面纹理横向平铺，所以多宽都不会被拉伸。
- 海鸥和浪花可以做 2 到 4 帧的循环动画；开了 `prefers-reduced-motion` 时就停住。
### 5.2 分类导航 CategoryNav
- 桌面和带鱼屏：左侧竖排的像素按钮，宽 200px，每个按钮带一个像素小图标和分类名。
- 手机：顶部一排可以横向滑动的像素按钮，固定在页面顶部。
- 状态：默认是 cream 底；悬停时描边变成 sea；选中时 sea 底配白字，并有按下的效果；键盘聚焦时用全站统一的 ink 描边加 sun 环。
### 5.3 菜品卡片 DishCard（基于 shadcn Card）
- 结构：照片（正方形 1:1，`object-cover`，外面套 2px 像素框）、菜名（最多两行，超出用省略号）、分类小标签、“+加到哪天”按钮。
- 状态：
  - 默认。
  - 悬停：卡片向上移 2px。
  - 已排进本周：右上角贴一个 sun 色像素角标「已点×N」。
  - 没有照片：显示像素风的盘子占位图，加上菜名的首字。
  - 加载中：用像素格子做的骨架屏。
- 点照片打开详情抽屉（Sheet），可以看大图和 Notion 里的说明。
### 5.4 “加到哪天”弹层 AddToDayPopover
- 点“+加到哪天”弹出一个 7×3 的小网格，横向是周日到周六，纵向是早、中、晚，点一个格子就加进去，再点一次就取消。
- 宽度小于 1024 时改用底部抽屉（Drawer），每个格子至少 44×44px。1024 及以上用浮层。
- 这是主要的排菜方式。拖拽只在桌面上做，算锦上添花。
### 5.5 一周菜单板 WeekBoard
- 样子像码头上的木排班板：表头 sea-deep 底配像素字，周日到周六 7 行，早、中、晚 3 列。
- 每个格子放这道菜的小缩略图（32px）和菜名。菜名最多两行，汉字按字换行，超出才省略。完整菜名放在 `title` 上，读屏也读全名。缩略图和 × 叠在菜名左侧，按钮不压住文字。星期列收成 32px、格子左右内边距收成 4px，这样 380 宽的面板里一行大约能排下四个汉字。一个格子可以放好几道菜，放不下就显示 +N。
- 今天那一行左边加一条 coral 色竖条。
- 空格子：虚线像素框，里面写着浅色的“空着呢”。它不是按钮，也不能 Tab 停在上面。
- 操作：格子里每道菜都有一个 × 用来移除；面板顶部能切换上一周、本周、下一周。
- 桌面上可以把菜品卡片拖进格子（用 dnd-kit），拖动时目标格子高亮成 sun 色。
### 5.6 一周菜单的三种摆法
- 小于 1024：只有底部托盘，sea-deep 底，写着“本周已点 N 道”。点一下在本页展开一周菜单，再点一下收起。
- 1024–1439：只有“本周 N”按钮，点开右侧抽屉。底部托盘按钮从 1024 起隐藏。
- 1440 及以上：一周菜单是右侧常驻面板，没有再打开它的按钮。
### 5.7 登录页
- 全屏码头场景，中间一块 cream 木牌，上面是用户名、密码和像素按钮“开店”。
- 密码错误时木牌左右轻轻晃一下，再显示 coral 色的提示文字；被限流时显示“歇会儿再试”加倒计时。

## 6. 响应式布局
| 断点 | 宽度 | 布局 |
|---|---|---|
| 手机 | < 640 | 顶部分类横向滑动，菜品 2 列，底部托盘展开一周菜单 |
| 平板 | 640–1023 | 菜品 3 列，同样用底部托盘展开一周菜单 |
| 小桌面 | 1024–1439 | 分类栏 200，一周菜单是抽屉，菜品网格 `minmax(200px, 1fr)`（大约 3 到 4 列） |
| 桌面 | ≥ 1440 | 一周菜单常驻，宽 380，菜品网格 `minmax(200px, 1fr)` |
| 大屏 | ≥ 1920 | 一周菜单 420 宽，菜品网格 `minmax(220px, 1fr)` |
| 带鱼屏 | ≥ 2560（目标 3440×1440） | 分类栏 220，一周菜单 480 宽，菜品网格 `minmax(280px, 1fr)`，间距 20；3440 宽时内容区至少 3200，左右留白各不超过 120 |
- 菜品网格用 `repeat(auto-fill, minmax(...))`，列数随宽度增加，卡片按格子分宽。
- 换周用地址栏的 `week` 参数，值是周日那天的 `YYYY-MM-DD`。分类筛选继续用 `category`，两个参数互不影响。
- 留白里只放码头木桩、救生圈这类小装饰，背景平铺不算填满宽度。
- 像素素材缩放倍数：手机 2x，桌面 3x，带鱼屏 4x。

## 7. 交互状态和反馈
- 加入成功：卡片角标变成「已点×N」，一周菜单里出现这道菜，并弹出 toast“已加到 周三·晚”。失败时弹出一条短的错误 toast，界面回到服务器上的结果。
- 两台手机同时排菜：以服务器为准，刷新后合并；有冲突时 toast 提示“菜单刚被家人改过，已更新”。
- 空状态：如果这周什么都还没点，显示像素小船加一句“这周还没点菜，去菜单挑挑吧”和一个按钮。
- 出错：像素风的木牌提示，加一个“重试”按钮。

## 8. 素材清单（要我们自己做）
场景横幅（左段、右段、可平铺的中段）、沙纹平铺图、9-slice 卡片边框、按钮三种状态、分类图标（家常菜、汤、海鲜、主食、甜点、凉菜，每个 16×16）、盘子占位图、空状态小船、留白装饰（木桩、救生圈）。全部导出成 PNG 或 WebP，单张大图不超过 300KB。
